    网站说明

    本站是《猫和老鼠》手游玩家自建的点位查询站，收录挂机果盘、几何桶、贯穿线等玩法的点位。 地图数据与命名以社区资料站为准，点位内容由玩家投稿、管理员审核后展示，供大家游戏时快速查用。 项目已在 GitHub 开源，欢迎反馈问题或参与建设。

    使用指南
    1. ① 顶部选择分类 → 地图主题 → 具体地图，浏览已审核点位
    2. ② 点击点位卡片可查看原图与描述，多图可左右翻页
    3. ③ 点开地图大类或具体地图后，点击右下角「投稿」卡片上传点位截图，分类与地图会自动填好
    4. ④ 投稿经管理员审核通过后，将在对应地图下展示
